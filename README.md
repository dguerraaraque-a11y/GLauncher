# 🚀 GLauncher - El Launcher de la Comunidad

![GitHub License](https://img.shields.io)
![Java Version](https://img.shields.io)
![Status](https://img.shields.io)

**GLauncher** es un lanzador de Minecraft de código abierto, diseñado por **DaniCraftYT25**. Este proyecto nació con el objetivo de ofrecer una herramienta ligera, rápida y optimizada para jugar Minecraft con mods, especialmente para PCs de bajos recursos.

---

## ✨ Características Principales
*   ⚡ **Alto Rendimiento:** Optimizado para consumir el mínimo de RAM posible.
*   📦 **Gestión de Modpacks:** Instalación sencilla de los paquetes de mods de mis series.
*   🎨 **Personalización:** Soporte para capas, skins y temas visuales.
*   🛠️ **Código Abierto:** Basado en Java para máxima compatibilidad.

---

## 🚀 Cómo Empezar

### Requisitos
*   Tener instalado **Java 8** o superior.
*   Windows (compatible con los archivos `.bat` incluidos).

### Instalación
1. Descarga el repositorio o ve a la sección de [Releases](https://github.com).
2. Ejecuta `build.bat` para compilar los archivos necesarios.
3. Inicia el programa usando `run.bat`.

---

## 🛠️ Archivos del Proyecto
*   `build.bat`: Compila el proyecto y prepara el entorno.
*   `run.bat`: Ejecuta el launcher directamente.
*   `generar_exe.bat`: Crea un ejecutable para que sea más fácil de abrir.
